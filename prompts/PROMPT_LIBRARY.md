# Prompt library (annex)

Every prompt is a versioned file `prompts/<station>/v<N>.md` (or `prompts/reader/<prompt>_v<N>.md`). Each file has a header with its role, technique, date and change vs the previous version. Old versions are never edited. Numbers are measured: dev numbers chose the version, test numbers were reported once (labels and result folders in each row). Code guards that change what a prompt's output can do are listed in their own table (last section), because they are not prompts.
