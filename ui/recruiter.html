HireSignal · Recruiter

One job, up to 3 candidates, the same requirements for each, evidence side by side. You decide. Single-CV demo page →

1. Job

The Job Agent (station /job, prompt v2) reads the text once and proposes a requirement card. You confirm it in step 2.

Skips the extraction. The demo cards are in demo/.

Job text and .txt only: the Reader keeps document text private and does not return it, so PDF/DOCX job files are not accepted here.

2. Confirm the requirements

Every candidate is checked against exactly this list. Edit texts, switch must / nice, set minimum years and skill terms. Select rows and press Merge to turn "Pyro / PyMC3 / JAGS or similar" back into one requirement.

3. Candidates (1 to 3)

Candidates are shown as A, B, C in upload order. File names are not shown (they can contain names).

4. Compare & decide

Columns: invite, then review, then reject, then upload order. There is no ranking and no score here: the system checks each requirement and shows the evidence; you decide.
